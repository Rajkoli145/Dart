# Profile Card - Assignment 3

Flutter screen showing a profile card. Built for my Flutter assignment to practice layout widgets and custom theme colors.

## What it does

- Profile card with avatar, name, role, location, and stats
- Uses `Column`, `Row`, `Container`, `CircleAvatar`, `Text`, and `Icon`
- Custom color palette instead of default Material colors

## Files

- `lib/app_colors.dart` - the custom color palette
- `lib/profile_stat.dart` - `ProfileStat` model and the column widget that shows one stat
- `lib/profile_card.dart` - `ProfileCard`, the actual card layout
- `lib/main.dart` - `ProfileApp` and `ProfileScreen`, wires everything together and runs it

## How to run

```
flutter run
```
